
# Student Grade Manager

## Project Overview
Student Grade Manager is a Python-based web application
developed using Streamlit and Pandas.

It helps manage student marks, calculate grades and
analyze academic performance.

## Features
- Add student details
- Enter student marks
- Automatically calculate grades
- Display student records
- Calculate class average
- Find highest and lowest marks
- Display grade distribution chart
- Download student results as CSV

## Technologies Used
- Python
- Streamlit
- Pandas

## Grade Criteria

| Marks | Grade |
|-------|-------|
| 90-100 | A+ |
| 80-89 | A |
| 70-79 | B |
| 60-69 | C |
| 50-59 | D |
| Below 50 | F |

## Installation

Install the required libraries:

pip install -r requirements.txt

## Run Application

streamlit run app.py
